IPv6 不是"更长的 IPv4"，它把地址、发现机制和报文头一起重做了：128 位地址、没有广播、用 NDP 取代 ARP、地址可以自动生成。

## 地址长什么样

128 位写成 8 组十六进制，用 `::` 压缩连续的 0（只能出现一次）：

```
2001:0db8:0000:0000:0000:0000:0000:0001  →  2001:db8::1
```

常见类型：

- **全球单播** `2000::/3`：公网可路由地址；
- **链路本地** `fe80::/10`：每接口自动生成，只在同一链路有效，路由协议的下一跳常用它；
- **唯一本地** `fc00::/7`：类似私有地址；
- **组播** `ff00::/8`：IPv6 没有广播，用组播替代；
- **回环** `::1`。

一个接口通常同时有链路本地地址和全球单播地址；`/64` 是标准子网长度，便于 SLAAC 自动配置。

## NDP：ARP 的替代者

邻居发现协议（NDP）基于 ICMPv6：

- **NS/NA**：解析邻居的 MAC（类似 ARP）；
- **RS/RA**：路由器通告前缀与默认网关，主机据此 **SLAAC** 自动生成地址；
- **重定向**：告诉主机更优的下一跳。

因为不再有广播，NDP 用**被请求节点组播**（`ff02::1:ffXX:XXXX`）精确询问，减少无关主机打扰。

## 配置与验证

```
华为/华三：
interface g0/0/1
 ipv6 address 2001:db8:10::1/64
ipv6 route-static 2001:db8:20:: 64 2001:db8:10::2
思科：
interface g0/0
 ipv6 address 2001:db8:10::1/64
ipv6 route 2001:db8:20::/64 2001:db8:10::2
```

验证：`show ipv6 interface brief` / `display ipv6 interface brief`、`show ipv6 route` / `display ipv6 routing-table`、`ping ipv6 2001:db8:20::2`。

## 过渡：双栈优先

最稳妥的过渡是**双栈**：接口同时配 IPv4 与 IPv6，应用按 DNS 结果选择。还有 NAT64/DNS64、6PE/6VPE、隧道等方案，但双栈是基础。
