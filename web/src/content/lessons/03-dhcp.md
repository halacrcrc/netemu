手动给每台 PC 配 IP、掩码、网关、DNS——50 台机器就是 200 次输入。DHCP 让主机接入网络时**自动拿到全部参数**。

## DORA 四步舞

```
客户端                         服务器
  │ ── Discover（广播）──→ │
  │ ←── Offer ──────────  │
  │ ── Request（广播）──→ │
  │ ←── Ack ────────────  │
```

- Discover 时客户端**还没有地址**：源 IP 是 0.0.0.0，目的 255.255.255.255——这也是跨网段 DHCP 需要"中继"的原因。
- 服务器选池的依据：**从哪个接口收到请求，就用与该接口同网段的池**。

## 服务器下发了什么

不只是 IP 和掩码：**默认网关**（option 3）和 **DNS**（option 6）同样关键——没有网关，客户端出不了网段。

## 租约与冲突

服务器维护租约表：已分出的地址不会重复下发（第二台主机自动拿下一个空闲地址）。真实设备还有租期与续租（50% 时单播 Request 续租），本模拟器简化为无期限。

## 动手

打开实验四「企业上网」：配置地址池，PC 在属性面板开启"DHCP 自动获取"，观察它自动拿到 192.168.1.2 和网关。
