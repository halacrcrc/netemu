路由器每收到一个包，都要回答一个问题："目的地址走哪个出口？"答案来自**路由表**。静态路由是人工写进表里的条目，简单、可控，也是理解动态路由的基础。

## 路由表怎么选

一条路由包含：目的网段/前缀、下一跳或出接口、优先级（AD）、度量值。转发时按顺序比较：

1. **最长前缀匹配**：/32 优于 /24，/24 优于 /0；
2. 前缀相同再比**优先级**（思科 AD / 华为-华三 preference），数值越小越优；
3. 优先级相同再比**度量值**（cost）。

优先级数值因厂商而异，常见默认值：

```
思科：直连 0、静态 1、eBGP 20、OSPF 110、iBGP 200
华为/华三：直连 0、静态 60、OSPF 10、IS-IS 15、BGP 255
```

所以一条静态默认路由可以"兜底"所有未知目的；要让它给动态路由让路，就把静态路由的优先级调大（浮动静态）。

## 默认路由与浮动静态

- **默认路由** `0.0.0.0/0`：匹配所有目的，常用于出口；
- **浮动静态**：给备份静态路由配一个更大的优先级，主路由消失时才生效。

```
华为/华三：
ip route-static 0.0.0.0 0 10.0.0.1
ip route-static 192.168.2.0 24 10.0.0.2 preference 200
思科：
ip route 0.0.0.0 0.0.0.0 10.0.0.1
ip route 192.168.2.0 255.255.255.0 10.0.0.2 200
```

下一跳必须**递归可达**：如果 10.0.0.1 本身没有直连或路由，静态路由不会进表。

## 排错顺序

1. `display ip routing-table` / `show ip route` 看目标网段是否存在；
2. 检查下一跳是否可达、出接口是否 Up；
3. 检查是否被更长前缀或更低优先级的路由覆盖；
4. 检查回程路由——ping 不通经常是"去程有、回程无"。

## 动手

打开实验九：DSW 配 `ip route-static 0.0.0.0 0 10.0.0.1` 指向 VRRP VIP，核心再配回程网段。先用 `display ip routing-table` 确认默认路由，再逐跳 ping 网关、核心、公网。把默认路由删掉，观察哪些流量立刻中断。
